# Story Archivist

触发后**立即执行**全部步骤，无需逐步确认。只读写固定路径。

## 触发

- `/archive_stories`、`/story-archivist`
- 「归档故事」「故事归档」「执行 story-archivist」
- 要求将 `domainConceptStory` 故事分类写入 `domainConcept` 或更新思维导图

## 固定路径

（相对项目根目录。）

| 用途 | 路径 |
|------|------|
| 默认源文本 | `domainConceptStory/originalStory.txt` |
| 故事归档根 | `domainConceptStory/domainConcept/{领域}/` |
| 思维导图（XMind） | `domainConceptStory/思维导图.xmind` |
| 思维导图（浏览器） | `domainConceptStory/思维导图.html` |

约束：

1. 未另行指定源时，读取默认源全文。
2. 用户指定打开文件/选中文本时，以其为源；归档与导图仍写上表路径。
3. 每次归档**同步重写** `.xmind` + `.html`；**永不删除**历史故事节点与已有故事文件。
4. **禁止**生成 `思维导图.md`、`思维导图.mm`；若残留则删除。

## 执行清单

```text
Task Progress:
- [ ] 1. 读取源文本
- [ ] 2. 解析全部独立故事块（含标题、正文、简述）
- [ ] 3. 按映射表分类
- [ ] 4. 增量写入 domainConcept（不删不覆盖）
- [ ] 5. 合并并写回思维导图（.xmind + .html，标题/描述父子拆分）
- [ ] 6. 输出统计报告
```

## 1. 解析故事

标题识别（任一命中）：

1. Markdown：`**标题**` / `## 标题` / `# 标题`
2. 纯文本：单独成行短标题（约 2–20 字），后接叙事正文

完整块结构：

```text
标题
故事正文
——故事完——          ← 可选
概念解释
隐喻对应 / 延伸说明
```

结束于：下一故事标题、或「继续下一个 / 规划草稿」噪声、或文件结尾。

提取字段：

| 字段 | 说明 |
|------|------|
| 故事标题 | 节点名 / 文件名 |
| 完整正文 | 故事 + 概念解释 + 隐喻对应 |
| 简述 | 供导图子节点；见「简述规范」 |

**忽略**：`继续下一个` 之后、下一正式标题之前的选题草稿 / 自言自语 / 大纲。

## 3. 增量写入故事文件

路径：`domainConceptStory/domainConcept/{领域}/{故事标题}.md`

| 情况 | 动作 |
|------|------|
| 文件不存在 | 新建 |
| 已存在且正文相同（可忽略首尾空白 / Frontmatter） | **跳过** |
| 已存在且正文不同 | 另存 `{标题}_v2.md`、`_v3.md`…（最小未占用版本号） |

**禁止删除或覆盖**已有故事文件（含源文本已移除的故事）。

Frontmatter：

```markdown
---
title: 故事标题
category: 领域文件夹名
source: domainConceptStory/originalStory.txt
archived_at: YYYY-MM-DD
---

（完整正文）
```

格式：`{核心概念中文名}：{一句人话解释}`（约 20–40 字）  
来源：优先「概念解释」首句提炼。

## 5. 思维导图结构（强制）

### 5.1 树形契约

```text
AI & 认知寓言
├── 用寓言理解智能、认知与复杂系统          ← 根描述（唯一）
├── {领域名}
│   ├── {领域简述}                          ← 领域描述（第一个子节点）
│   ├── {故事标题}
│   │   └── {故事简述}                      ← 故事描述（唯一子节点）
│   └── …
└── 未分类_待标注
    └── 尚未归入明确领域的故事
```

硬性规则：

1. **标题 / 描述父子拆分**：描述只能是子节点，不得与标题同层同节点。
2. 领域下子节点顺序：先领域简述，再按故事标题**字典序**排列故事。
3. 空领域仍保留「领域名 → 领域简述」两层。
4. `_v2` / `_v3` 不单独占导图节点；只保留主标题。
5. 未知新领域插入在 `未分类_待标注` 之前，并自拟同等长度领域简述。
6. 合并数据源：已有 `.xmind` 节点与简述 + `domainConcept/**/*.md` 主标题 + 本次解析；同标题跨领域以本次分类为准。

- 用寓言理解智能、认知与复杂系统

### 5.4 反例（禁止）

```text
❌ 镜中河\n二阶控制论：…          （同节点换行）
❌ 镜中河：二阶控制论：…          （同行拼接）
❌ title=镜中河 + notes=简述      （用备注代替子节点）
❌ 只写故事名、无描述子节点
❌ 生成 .md / .mm 导图
```
