Ragas 评估集成
问：如何在 Spring AI 应用中集成 Ragas 评估框架？请给出 CI 流水线设计思路。
答：建议 Docker 化 Python Ragas 服务 HTTP 调用；CI 中跑数据集、算 context_recall 等指标并设质量门禁；Java 侧可用 Dokimos 等做轻量评估。

可观测性大盘（Prometheus + Grafana）
问：在 Spring AI 中如何基于 Micrometer 为 RAG 链路建立性能基准和监控大盘？
答：接入 micrometer-registry-prometheus，暴露 actuator 指标；Grafana 看 LLM/向量客户端耗时与 RAG 相关 score，并配置 p99、Token 突增等告警。
