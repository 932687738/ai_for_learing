## EmbeddingModel 与本地 ONNX 模型

> **模块**：向量与嵌入 | **标签**：向量与嵌入 | **更新**：2026-05-28

### 核心概念

返回值：`EmbeddingResponse`，封装 `List<Embedding>`，每个 Embedding 为浮点向量。

### 要点

- **返回值**：`EmbeddingResponse`，封装 `List<Embedding>`，每个 Embedding 为浮点向量。
- **本地 ONNX 实现**：`OnnxEmbeddingModel`（来自 `spring-ai-transformers` 依赖），通过 `OnnxEmbeddingModelConfig` 指定模型目录与运行设备。

### 代码示例

```java
OnnxEmbeddingModelConfig config = new OnnxEmbeddingModelConfig(
    "path/to/all-MiniLM-L6-v2/",  // 模型目录
    "cpu"
);
EmbeddingModel embeddingModel = new OnnxEmbeddingModel(config);
```

**答**：返回值**：`EmbeddingResponse`，封装 `List<Embedding>`，每个 Embedding 为浮点向量。；本地 ONNX 实现**：`OnnxEmbeddingModel`（来自 `spring-ai-transformers` 依赖），通过 `OnnxEmbeddingModelConfig` 指定模型目录与运行设备。。

## VectorStore.similaritySearch 内部调用链

> **模块**：向量与嵌入 | **标签**：向量与嵌入 | **更新**：2026-05-28

### 核心概念

先用 EmbeddingModel 将查询文本 embed 为 queryVector，再按距离度量（如余弦）在向量库中排序取 Top-K，返回匹配的 Document 列表。

### 要点

先用 EmbeddingModel 将查询文本 embed 为 queryVector，再按距离度量（如余弦）在向量库中排序取 Top-K，返回匹配的 Document 列表。

### 代码示例

```java
// 伪代码
public List<Document> similaritySearch(SearchRequest request) {
    List<Double> queryVector = embeddingModel.embed(request.getQuery());
    // 执行 SQL: SELECT * FROM vectors ORDER BY embedding <=> queryVector LIMIT topK
    return database.search(queryVector, request.getTopK());
}
```

**答**：先用 EmbeddingModel 将查询文本 embed 为 queryVector，再按距离度量（如余弦）在向量库中排序取 Top-K，返回匹配的 Document 列表。
